# Мия — витрина паков артов

Статический сайт (GitHub Pages) + Supabase (БД, хранилище, Edge Function `unlock`).
- `index.html` — витрина: лента паков, медиа, уровни, об авторе, ввод кода.
- `admin.html` — админка владельца (вход по email+паролю).
- `config.js` — публичный адрес API и publishable-ключ (не секрет). Для России можно заменить `API_BASE` на адрес прокси.
