# Мия — витрина паков артов

Статический сайт (GitHub Pages) + Supabase (БД, хранилище, Edge Functions `login`, `register`, `unlock`).
- `index.html` — весь сайт: лента, медиа, уровни, профиль, комментарии; у владельца после входа — кнопка «Админка».
- `app.js` — витрина, `admin.js` — админка, `crop.js` — редактор обрезки (оригиналы не меняются).
- `config.js` — публичный адрес API и publishable-ключ (не секрет). Для России можно заменить `API_BASE` на адрес прокси.
